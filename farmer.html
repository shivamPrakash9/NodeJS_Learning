Software Requirements Specification

🌱 Agri-Logistics & Digital Marketplace (SIH)

1. 🎯 Project Overview & Scope

  • Core Problem: Intermediaries drastically reduce farmer profits and inflate consumer prices.
  • Proposed Solution: A D2C/B2B marketplace directly connecting FPOs/Farmers with bulk buyers.
  • Key Innovators: AI-based demand forecasting and automated 3PL (Third Party Logistics) route optimization.
  • Target Audience: Farmers (Sellers), FPOs (Aggregators), Restaurants/Retailers (Buyers), Fleet Owners (Transporters).

2. 🏗️ System Architecture & Data Flow

🌾 Farmers / FPOs
(List Produce)
→
💻 Cloud Marketplace
+ AI Forecasting Engine
←
🛒 Bulk Buyers
(Place Orders)
↓ (Dispatches optimized routes) ↓
🚚 Logistics Partners
(Pickup & Delivery)

3. ⚙️ Functional Requirements

Module Features / User Stories Priority
Marketplace Core • Role-based login (Farmer, Buyer, Driver)
• Product listing with real-time inventory pooling for FPOs
• Payment Gateway / Escrow system integration 		High (P0)
AI Demand Forecasting • Analyze historical mandi prices and weather data
• Provide actionable alerts ("Hold onions for 3 days for +15% price") 		High (P0)
Smart Logistics & Routing • Auto-group nearby farm pickups into a single truck route
• Driver portal for bid acceptance and live navigation mapping 		High (P0)
Multi-lingual UI • Voice-to-text search in regional languages (Hindi, Gujarati)
• SMS-based fallbacks for low-bandwidth areas 		Med (P1)

4. 🔒 Non-Functional Requirements (NFR)

Category Requirements
🚀 Performance • Page load < 2 seconds.
• Route optimization algorithm executes in < 5 seconds.
🛡️ Security • JWT Authentication for API endpoints.
• End-to-end encryption for payment data.
📱 Usability • Mobile-first Progressive Web App (PWA) design.
• Minimal text; icon-heavy UI for accessibility.

Frontend: React.js Tailwind CSS PWA

Backend & DB: Node.js (Express) PostgreSQL / Supabase Redis (Caching)

AI / ML: Python (FastAPI) Scikit-learn Pandas

3rd Party APIs: OSRM / Google Maps API Agmarknet Data API Twilio (SMS)
